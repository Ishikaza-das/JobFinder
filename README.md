# 🏢 Job Searching Website

## Overview
Welcome to the Job Searching Website! This platform serves as a bridge between job seekers and companies. Job seekers can explore opportunities, upload resumes, and apply for jobs, while companies can post job openings and manage applicants effectively.

## 🌟Features

👨‍💻**For Job Seekers:**
- 🔍 Browse Jobs: Explore a wide range of job openings across various industries and locations.
- 🎯 Filters and Search: Narrow down job listings based on keywords, location, job type, salary range, and more.
- 📄 Resume Upload: Upload and manage your resume directly on the platform to apply for jobs seamlessly.
- 📊 Personalized Dashboard: Track your applications, view saved jobs, and manage your profile.
- 📩 Job Alerts: Get notified about new job postings that match your preferences.

🏢 **For Companies:**

- 📝 Post Job Openings: Create detailed job postings, including job description, requirements, and benefits.
- 📂 Manage Applicants: View applications, shortlist candidates, and track the hiring process.
- 💼 Company Profile: Showcase your company with a dedicated profile that highlights your brand and values.
- 🔍 Resume Search: Access the pool of uploaded resumes to find potential candidates.
  
⚙️ **General Features:**

- 🔒 Authentication: Secure login and signup for both job seekers and companies.
- 📱 Responsive Design: User-friendly interface optimized for desktop and mobile devices.
- 🔗 Integration: Support for third-party integrations like LinkedIn, Google Calendar, and email notifications.

## 🚀Getting Started

**Prerequisites**
- Node.js and npm
- MongoDB
- React.js

**Installation**

**Clone the Repository:**
- git clone (https://github.com/Ishikaza-das/JobFinder.git)
- cd job-searching-website

**Backend Setup:**
- cd ../backend
- npm install

**Frontend Setup:**
- cd ../frontend
- npm install

**Environment Variables:** Create .env files in both frontend and backend directories and configure:
- Backend: Database URI, JWT secret, etc.
- Frontend: API base URL, environment-specific variables.

**Run Backend:**
- cd ../backend
- npm run dev

**Run Frontend:**
- cd ../frontend
- npm run dev

## 🛠️ Technologies Used

**Frontend:**

**Backend:**

## 📋 Usage

**For Job Seekers:**
- Sign up and create your profile.
- Upload your resume.
- Search and apply for jobs using advanced filters.
